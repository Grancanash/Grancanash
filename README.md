# 💫 Quien soy?
Hola<br><br>Soy un desarrollador web apasionado por crear interfaces limpias, responsivas y fáciles de usar. Mi enfoque son las tecnologías tradicionales de frontend como HTML, CSS, JavaScript y los frameworks y librerías clásicas derivadas: Bootstrap, Tailwind, jQuery, SASS, FlexBox, Grid, Typescript, etc. También tengo alta experiencia desarrollando y personalizando sitios web con WordPress y los constructores y temas más populares como Elementor, Divi, Salient, etc.<br><br>Actualmente estoy completando un máster en desarrollo fullSstack, donde estoy profundizando mis habilidades en Python, Django, SQL y React entre otros, además de aprender más sobre arquitecturas modernas para aplicaciones web. Me encanta entender cómo se conectan el frontend y el backend para crear soluciones más robustas y centradas en el usuario.<br><br>Siempre estoy buscando oportunidades para colaborar en proyectos interesantes, contribuir al desarrollo de software y seguir creciendo como programador. Si también te gusta el código limpio, una buena experiencia de usuario y las tecnologías web modernas, seguro tenemos cosas de las que hablar 😊

[![Demo](https://img.shields.io/badge/Demo-En%20Vivo-blue?style=for-the-badge&logo=google-chrome)](https://crm.grancanash.es)

Sistema profesional de gestión de clientes diseñado para equipos de ventas. Implementa una arquitectura robusta con seguridad JWT, base de datos relacional y una interfaz de usuario moderna centrada en la productividad.

- **🎯 Core:** CRUD completo de Clientes y Empresas con filtrado dinámico por Agente.
- **📊 Inteligencia:** Dashboard con gráficos de distribución de cartera y métricas en tiempo real.
- **📅 Agenda:** Sistema de tareas con control de vencimiento y registro inmutable de actividad.
- **🛠️ Stack Técnico:** Django, React, PostgreSQL, Docker, Nginx, Tailwind v4 y Recharts.
