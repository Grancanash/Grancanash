<br>

> Tienda online demo con temática de plantas alienígenas. Desarrollada con **Django REST Framework** (backend) y **React + TypeScript + Tailwind CSS** (frontend). Incluye carrito de compra, checkout como invitado, autenticación JWT + Google OAuth, panel de administración personalizado y reset diario automático del catálogo.

- 🛍️ **Catálogo completo:** 30 productos con imágenes, sistema de categorías, búsqueda y filtros.
- 🛒 **Carrito & Checkout:** Gestión de cantidades, pedidos como invitado o usuario registrado, formulario de envío.
- 🛡️ **Panel Admin React:** CRUD de productos, categorías y pedidos desde interfaz personalizada (sin usar el admin de Django).
- 🔄 **Reset diario automático:** Cron que restaura la tienda a su estado original cada noche a las 00:00.
- 📧 **Notificaciones:** Envío de email de confirmación vía IONOS SMTP en producción.
- 🔐 **Seguridad:** Doble capa de permisos (Django `is_staff` + `is_store_admin` personalizado), JWT con payload extendido.

</details>
